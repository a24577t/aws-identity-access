# Wayfinding result records

`docs/wayfinding/map-<n>/<NN>-<stable-title>.md` holds one ordinary Markdown result record per
Wayfinder ticket (`NN` = issue number, zero-padded).

- Wayfinder result files are **proposed discovery records** — never accepted architecture.
- **Git history provides durability**; corrections are ordinary commits.
- **GitHub remains the workflow, dependency, and index surface**: the ticket's resolution
  comment and the map issue link to the committed record.
- **Accepted architecture occurs only through ⟦G-Accept⟧**
  (`.ai/repository/methodology/skill-execution-map.md`); every record carries
  `architectural_status: proposed` until then.
